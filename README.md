## setoolkit-zphisher-quishing
This project demonstrates a multi-tool social engineering attack vector known as Quishing (QR Code Phishing) in a controlled lab environment.  By combining Zphisher for credential harvesting and SEToolkit (Social-Engineer Toolkit) for dynamic QR code generation,


#Project Overview

- This repository documents a proof-of-concept simulation exploring Quishing (QR Code Phishing) within a controlled security testing environment.
- The lab combines credential harvesting templates with dynamic QR code generation to analyze how traditional URL-based social engineering can be adapted into physical or image-based attack - vectors.

## Step 1: Starting Zphisher

First, open the terminal, move into the Zphisher directory, and launch the tool:

``bash
cd zphisher
sudo bash zphisher.sh

## Step 2: Selecting the Target Template

- After launching Zphisher, the tool displays a list of available service templates

- For this test, I chose option `04` (Microsoft) to load the Microsoft login template for the setup


## Step 3: Selecting Port Forwarding Service

- Next, Zphisher prompts to choose a port forwarding service to expose the local server[cite: 4]:

- <img width="1920" height="920" alt="Screenshot_2026-10-15_13_43_55" src="https://github.com/user-attachments/assets/d44446a0-897a-4280-ac89-0685d62f9b6f" />

- Option `01` (Localhost) hosts the page only on the local network

- Option `02` (Cloudflared) generates a public URL accessible over the internet.

- For this setup, option `02` (Cloudflared) was selected to generate a public link that can later be converted into a QR code.

## Step 4: Local Server Initialization & Listener Setup

- Once the port forwarding option is selected, Zphisher starts the local PHP server and initializes the listener

- <img width="1920" height="920" alt="Screenshot_2026-10-15_13_44_08" src="https://github.com/user-attachments/assets/2e3835b1-a691-40ea-aefb-cc51059d97b8" />

- Local Hosting: The template is successfully hosted locally on `http://127.0.0.1:8080`

- Listener Status:** The terminal enters a waiting state (`Waiting for Login Info...`) to log incoming network connections and input in real time

- Next step is to take the public URL generated by Cloudflared and pass it into SEToolkit for QR code generation.


## Step 5: Setting Up Cloudflare Tunnel Manually
